# Drogaria Morais

Landing page estática da Drogaria Morais, em Palmares, Belo Horizonte.

## Publicação na Vercel

Importe este repositório na Vercel. O projeto usa HTML, CSS e JavaScript sem etapa de build. O arquivo `vercel.json` define `dist` como diretório publicado.

## Prévia local

Na raiz do projeto, execute `python -m http.server 4173 --directory dist` e abra `http://localhost:4173`.

## Conteúdo

Antes de veicular anúncios, confirme o WhatsApp e os horários da loja. Os ícones da seção de produtos são da [Lucide](https://lucide.dev/) e a licença está em `dist/icons/LICENSE.txt`.
